# StudySpot Landing Page

This repository contains two versions of the StudySpot landing page:

- **Plain CSS:** `plain-css/index.html` with styles in `plain-css/style.css`
- **Tailwind CSS:** `tailwind/index.html`

## Workflow

I first created the landing page using plain HTML and CSS. I then rebuilt the same page with HTML and Tailwind CSS. The page content and overall design are similar in both versions; the main change is how the styling is applied. I organized the two versions into separate folders so they are easy to compare.
